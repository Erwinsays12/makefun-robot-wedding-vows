Entry for the [One-Line Robot Wedding Vows](https://make.fun/c/u-kreutzx-one-line-robot-wedding-vows-a154ba4b) competition on [make.fun](https://make.fun).

## What it does

`main.ts` writes one line of wedding vows for a robot couple to `/output/entry.txt` — a classic vow ("in sickness and in health") that runs through firmware updates, reboots and drained batteries, and lands its joke in the last few words: *till low battery do us part.*

## Run it

```sh
node main.ts
```

It prints the character count (150, within the 1–160 limit) and writes the vow to `/output/entry.txt`.
